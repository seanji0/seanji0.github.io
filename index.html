Golf SimulatorBrowser game

A golf simulator in a single file. Enter your handicap and club distances, then play a par-4 by choosing lines, clubs, chips and putt reads. Every shot comes from a dispersion model of your own game.

HTML / CSS / JavaScript
Open the live app  ·  View the code on GitHub
  • Setup: handicap, go-to miss, putting touch and a club picker with your carry distances.
  • Shot model: spread and distance variance scale with handicap and lie. Water adds a penalty.
  • Aiming: click a target line and see live distances.
  • Short game: chip type depends on the lie.
  • Putting: color-coded arrows show break and speed.
  • Animated ball flight, undo, and mid-round club edits.

HTML / CSS / JavaScript
Open the live app  ·  View the code on GitHub
  • Frame stepping: arrow keys move one frame, shift moves five, space plays.

  • Download each still or the full swing card.
  • Private by design: video is processed in your browser and never uploaded.
SwingLabInstallable web app

A practice journal for golfers. Log every session, track real carry distances, and let an analysis engine surface patterns for you or your coach to interpret.

Next.js 14 / TypeScript / Tailwind CSS / PWA
Private repository.
  • Practice journal: range, round, lesson, mental and fitness sessions.
  • Yardage benchmarks: carry numbers tracked against skill levels.
  • Feels vs real: what a swing felt like next to what the data says.
  • Course strategy: plan each hole and decide where to miss.
  • AI caddie: patterns across your data, with a coach confirming each reading.
  • Bottleneck analysis: ranks speed, strike, launch, spin and path by potential gain.
